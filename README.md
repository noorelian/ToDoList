# To-Do List App:

A simple To-Do List built using HTML, CSS and some JavaScript.

## Features:
- Add new tasks
- Mark tasks as completed (check/uncheck)
- Delete tasks
- Persistent storage (tasks remain saved even after refreshing the page)

## Description:

This project allows users to manage their daily tasks efficiently through a clean and simple interface. All tasks are stored locally in the browser, so your list stays even after reloading the website.

## Technologies Used:
- HTML
- CSS
- JavaScript

*Simple and easy for daily use.*
